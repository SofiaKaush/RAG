# 🚀 Ultimate RAG App

Мощное локальное RAG-приложение (Retrieval-Augmented Generation) для анализа документов с использованием открытых моделей.

## 🎯 Возможности

- ✅ **Поддержка множества форматов**: TXT, PDF, JSON, Markdown
- ✅ **Локальные эмбеддинги**: Использует `sentence-transformers` - нет зависимости от OpenAI
- ✅ **Локальная LLM**: Интеграция с LM Studio для полной приватности
- ✅ **Оптимизированная индексация**: Умное разбиение текста с перекрытием
- ✅ **Встроенный веб-интерфейс**: Красивый UI с поддержкой Tailwind CSS
- ✅ **Статистика и управление**: Отслеживание документов, очистка БД
- ✅ **Системные промпты**: Улучшенная обработка запросов
- ✅ **Обработка ошибок**: Надежная валидация и логирование
- ✅ **Метаданные**: Отслеживание источников и временных меток

## 📦 Установка

### Требования
- Python 3.8+
- LM Studio (или совместимый OpenAI-совместимый API)

### Шаги установки

```bash
# Клонирование репозитория
git clone <repo>
cd RAG

# Установка зависимостей
pip install -r requirements.txt

# (Опционально) Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

## 🚀 Запуск

### 1. Запустите LM Studio
```bash
# Откройте LM Studio и загрузите модель, убедитесь что сервер запущен на localhost:1234
```

### 2. Запустите приложение
```bash
python app.py
```

### 3. Откройте в браузере
```
http://localhost:5011
```

## 🔧 Конфигурация

Переменные окружения:

```bash
# LLM сервер
export LLM_BASE_URL="http://127.0.0.1:1234/v1"
export LLM_API_KEY="lm-studio"
export LLM_MODEL="local-model"
```

### Параметры в коде
```python
CHUNK_SIZE = 800          # Размер одного чанка текста
CHUNK_OVERLAP = 100       # Перекрытие между чанками
N_SEARCH_RESULTS = 5      # Кол-во релевантных отрывков
```

## 📚 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|---------|
| GET | `/` | Веб-интерфейс |
| POST | `/upload` | Загрузить документ |
| POST | `/ask` | Задать вопрос |
| GET | `/stats` | Получить статистику |
| POST | `/clear` | Очистить базу данных |
| GET | `/health` | Проверка здоровья сервиса |

## 🎨 Примеры использования

### Загрузка документа
```bash
curl -X POST -F "file=@document.pdf" http://localhost:5011/upload
```

### Задание вопроса
```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"question":"О чем документ?"}' \
  http://localhost:5011/ask
```

### Получение статистики
```bash
curl http://localhost:5011/stats
```

## 🤝 Стек технологий

- **Backend**: Flask
- **Векторизация**: sentence-transformers (all-MiniLM-L6-v2)
- **Векторная БД**: ChromaDB
- **LLM**: OpenAI API compatible (LM Studio)
- **Frontend**: HTML5, Tailwind CSS
- **PDF обработка**: PyPDF2

## 📈 Производительность

- Эмбеддинги генерируются локально (быстро)
- Поиск по вектору использует оптимизированный индекс

## ❗ Требования к системе

- RAM: минимум 4GB
- GPU: опционально (ускоряет эмбеддинги)
- Место на диске: зависит от размера документов

## 🆘 Устранение неполадок

### "Connection refused" для LLM
- Убедитесь, что LM Studio запущена на localhost:1234
- Проверьте URL в `LLM_BASE_URL`

### "Model not found"
- Загрузите модель в LM Studio
- Убедитесь, что модель загружена перед запросом

### Медленные ответы
- Проверьте размер документов
- Уменьшите `N_SEARCH_RESULTS` для быстродействия
- Используйте GPU для ускорения эмбеддингов
