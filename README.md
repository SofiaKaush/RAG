# 🚀 Ultimate RAG App (Git Edition)

Автономная система RAG (Retrieval-Augmented Generation) для анализа локальных документов и кодовых баз. Приложение работает полностью локально, обеспечивая максимальную приватность ваших данных.

## Ключевые возможности

*   **Локальные эмбеддинги:** Векторизация данных происходит прямо на вашем процессоре (через `sentence-transformers`). Никаких лишних серверов!
*   **Индексация Git-репозиториев:** Просто вставьте ссылку на GitHub/GitLab, и приложение само скачает, распарсит и проиндексирует код проекта.
*   **Стриминг ответов:** Ответы нейросети приходят в реальном времени (эффект "печатающегося текста").
*   **Поддержка форматов:** TXT, Markdown, PDF.
*   **Темная/Светлая тема:** Современный UI с автоматическим переключением.
*   **Markdown + Code Highlighting:** Красивое отображение ответов и подсветка синтаксиса в коде.
