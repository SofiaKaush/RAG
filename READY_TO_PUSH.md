## 🆘 УСТРАНЕНИЕ ПРОБЛЕМ

### Ошибка: "nothing to commit, working tree clean"
```bash
# Это означает что всё уже закоммичено
# Проверьте статус:
git status
```

### Ошибка: "Permission denied (publickey)"
```bash
# Проблемы с SSH ключами
# Проверьте подключение:
ssh -T git@github.com

# Или используйте HTTPS:
git remote set-url origin https://github.com/SofiaKaush/RAG.git
```

### Ошибка: "fatal: not a git repository"
```bash
# Убедитесь что вы в правильной директории
cd /workspaces/RAG
git status
```

### Ошибка: "Merge conflict"
```bash
# Сначала обновитесь с сервера
git pull origin main
# Разрешите конфликты и попробуйте снова
git add -A
git commit -m "Resolve merge conflicts"
git push origin main
```
